**CuNi Studio + Agent Mode: Free Browser Playground Where Agent Law Is Exact Multi-Target Code**

*One source → identical Python, Go, and JavaScript—or the compiler refuses. Now with Agent mode: speech routes skills; only CuNi that passes exactness runs.*

**Web** — July 26, 2026 — **CuNi (Code:uNiTY)** today expanded its free hosted **Studio** at **https://cuni-studio.fly.dev/** with **Agent mode**, Notelog, Critic Book, and a skill writer that only adopts code after an exactness pass. CuNi is an open-source language (v0.1.6, MIT) that compiles a single program to Python, Go, and JavaScript under a strict **exactness contract**: portable programs must produce identical runtime behavior on every supported target, or the toolchain refuses to treat them as ready.

### The problem

Polyglot teams and AI agents ship logic that “works” in one runtime and drifts in another. Hand ports and approximate transpilers hide divergence until production. Chat-based agents encode policy only in prompts—unverified across Python workers, Go services, and JavaScript edges.

### The approach

- **Exactness gate (`cuni check`)** — emit and run py/go/js; require identical stdout  
- **CuNi Studio** — no install: edit, emit, run exactness in the browser  
- **Agent mode** — speech routes to CuNi skills; skills run only after exactness PASS  
- **Propose / adopt** — new law is quarantined until it is a “citizen” (exact)  
- **`link` interop** — shared HTTP+JSON contracts across languages  
- **Notelog + Critic Book** — lab journal and structured critiques
