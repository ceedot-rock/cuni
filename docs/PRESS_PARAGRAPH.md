# One-paragraph pitch (media / Paragraph / social)

**CuNi Studio** (https://cuni-studio.fly.dev/) is a free browser playground for **CuNi**, an open-source language that compiles one program to **Python, Go, and JavaScript** only if behavior matches on all three—otherwise it **refuses**—and its new **Agent mode** treats that exact CuNi as agent *law* (speech can route skills; nothing runs until `cuni check` passes), with Notelog, Critic Book, and propose/adopt for new skills; source and v0.1.6 release at https://github.com/ceedot-rock/cuni.
