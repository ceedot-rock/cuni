# Positioning (v0.1.7 era)

**Tagline (non-technical):**  
Critical rules that must mean the same in every runtime — or they don’t ship.

**Category:** Trust / control gate for multi-runtime policies (security-*relevant*, not a generic security suite).

## Who pays
Teams shipping agents or multi-runtime automation where a wrong policy costs money, access, or audit pain.

## Vertical (first)
**Spend / limits** — flagship Studio demo. Secondary: agent tool permissions under the same shape.

## First paid surface
**Private Studio workspace** — save policies, exactness history, publish/register audit trail.  
Later: API `check` + `register` for CI/agents.  
Not first: standalone Rider product or compiler licenses.

## Free forever
Public Studio + exactness demo (attention and proof).
