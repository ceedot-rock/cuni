Build with CuNi.

Four steps. Five minutes. Proof included.

  1. Install.
    $ cargo install cuni
  2. Write it.
    $ cat > hello.cuni
say "hello, exact world"
  3. Prove it.

    cuni check runs your program on every seat. Same bytes everywhere, or it refuses.

    $ cuni check hello.cuni
PASS — 12 seats, byte-identical
  4. Ship it anywhere.

    Emit for a chain, a language, a database.

    $ cuni --emit-vyper hello.cuni

Keep proving it.

The cuni-audit GitHub Action drops the exactness gate into any CI pipeline: law in, implementation in, signed receipt out. A moved boundary cent fails the PR.
